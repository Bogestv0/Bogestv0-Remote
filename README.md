# Bogestv0 REMOTE

Программа удалённого доступа для Windows: смотрите экран другого компьютера, управляйте им мышью и клавиатурой, слушайте звук, переписывайтесь в чате. Соединение зашифровано.

## Установка

1. Откройте раздел **[Releases](../../releases/latest)** и скачайте файл:
   * `Bogestv0-REMOTE-Setup-….exe` — **установщик** (рекомендуется): ставит программу и службу, добавляет автозапуск, даёт полный доступ к окнам администратора (UAC) и экрану входа.
   * `Bogestv0-REMOTE-Portable-….exe` — портативная версия, не требует установки (без службы: окно UAC придётся подтверждать на самом компьютере).
2. Запустите файл. Windows может показать окно «Windows защитила ваш компьютер» — программа пока не подписана сертификатом. Нажмите **Подробнее → Выполнить в любом случае**. Установщик ставит программу для всех пользователей компьютера, поэтому Windows попросит подтвердить права администратора.
3. Установите программу на **обоих** компьютерах — и на том, к которому подключаются, и на том, откуда подключаются.
4. После запуска вверху появится ваш ID из 9 цифр — по нему к вам подключаются.

Требования: Windows 10 или 11 (64-бит), доступ в интернет.

Программа запускается вместе с Windows свёрнутой в трей (значок у часов) и готова принимать подключения. Если запустить программу ещё раз (значок на рабочем столе, в меню «Пуск»), второе окно не откроется — развернётся уже запущенное, даже если оно свёрнуто или спрятано в трей. Закрытие окна не завершает программу; полностью выйти можно из меню значка в трее. Обновления она находит сама: когда выйдет новая версия, вверху появится кнопка **«Обновить»**.

## Как пользоваться

**Подключиться к компьютеру**
1. На вкладке **Устройства** нажмите **Добавить устройство**, введите ID того компьютера и название.
2. Нажмите **Подключиться** и выберите способ:
   * **С подтверждением** — на том компьютере появится окно «Разрешить / Отклонить».
   * **По паролю** — вход без ручного подтверждения (нужен пароль, заданный на том компьютере). Галочка **«Запомнить пароль»** сохранит его, и в следующий раз «Подключиться» войдёт сразу.
3. Кнопка **Обновить** на вкладке «Устройства» заново проверяет, какие компьютеры сейчас в сети.

**Разрешить входить по паролю** (на компьютере, к которому будут подключаться)
1. **Безопасность → Задать пароль** (минимум 8 символов) — можно сгенерировать.
2. Включите **«Вход без ручного подтверждения»**. Лучше ограничить круг устройств в **«Разрешённые устройства»**.
3. Галочка **«Подключившиеся по паролю сразу получают права администратора»** даёт полный доступ без дополнительных запросов — включайте только с длинным паролем и списком разрешённых устройств. Подтверждается один раз окном «Да/Нет» на этом компьютере; работает с установленной версией (Setup).

**В окне сессии**
* Кнопки внизу: управление мышью и клавиатурой / только просмотр, чат, ваш курсор над экраном, во весь экран (выход — кнопкой или Esc), выбор монитора, буфер обмена (отправить / получить текст), права администратора (щит; при входе по паролю запрашиваются только им), звук динамиков, микрофон, отключиться.
* **Чат** открывается справа; сообщения видны обоим участникам только во время сессии.
* Вкладка **Звук**: громкость, источник звука (весь системный звук или любое устройство ввода удалённого компьютера, например «Стерео микшер» или виртуальный кабель), микрофон удалённого компьютера, устройство вывода у вас.
* На компьютере, к которому подключились, окно программы само уходит в трей и не мешает; о каждом входе показывается уведомление. Отключить подключение можно в окне («Отключить сейчас») или из меню значка в трее.

**Настройки** (вкладка «Безопасность»): автозапуск с Windows, сворачивание в трей, соединение только через сервер, обновления, собственный сервер (по умолчанию используется встроенный), журнал подключений и диагностика соединения.

## Если что-то не работает

* Нет связи с сервером — проверьте интернет и брандмауэр, затем нажмите **Обновить** на вкладке «Устройства».
* Не удаётся подключиться — **Безопасность → Диагностика соединения → Скопировать** и пришлите текст разработчику.
* Не запускается при старте Windows — **Безопасность → Запускать вместе с Windows**: там показано, включён ли автозапуск. Если Windows его отключил — Диспетчер задач → Автозагрузка → Bogestv0 REMOTE → Включить.

## Удаление

Параметры Windows → Приложения → Bogestv0 REMOTE → Удалить (служба удаляется вместе с программой).
